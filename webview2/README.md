# Folio Dot Pig（FDP 极简版）

这是 Windows x64 便携版。启动 `FDP-Lite.exe` 时请保留整个目录。需要 Microsoft Edge WebView2 Runtime 和 .NET Framework 4.7.2 或更新版本；安装包不包含运行时。本机数据保存在当前用户的 LocalAppData/FDP-WebView2-Prototype，与 Electron 版分开。

开始页在未设为默认应用时提供设置入口。点击后程序会将 FDP 极简版注册到当前 Windows 用户并打开系统默认应用设置；请在系统中为 .pdf 选择名称带有当前版本号的 FDP 极简版。升级或移动程序后，请运行新版并重新设置默认应用。Windows 可能缓存应用名称和文件图标。

启动页显示最近打开的最多 5 个 PDF，可重新打开、移除或清空记录。程序最多保留 10 条记录，移除一条后较早的记录可能重新显示。记录仅包含文件路径和标识，清除记录不会删除 PDF。

支持多标签、连续阅读、缩略图、只读书签、缩放、适合宽度或页面、旋转阅读视图、选择复制已有文字、按页搜索、全屏演示及带预览的打印。可以将当前页导出为 PNG，也可以将多张 PNG/JPEG 图片转换为 PDF；页面按选择器返回的顺序排列，请检查图片方向和尺寸。搜索和复制受 PDF 编码和阅读顺序影响；扫描图片不支持文字识别。旋转阅读视图不改变文件或打印方向。

缩略图支持 Ctrl 多选和 Shift 连选，可批量删除选中的页面；Ctrl+Z 可撤销上一步修改。普通 PDF 可旋转、删除、前移和后移当前页，提取指定页，从电脑选择 PDF 插入或合并，在预览中调整页面顺序和移除页面、按页码分组拆分，以及在当前会话撤销修改。拆分时每组分别选择新文件名；中途取消会保留已经保存的文件。编辑后的标签显示圆点，关闭未保存文档会提示。“保存”（Ctrl+S）更新原文件；“另存副本”（Ctrl+Shift+S）创建新文件且不会覆盖已有文件。原文件在打开后被其他程序修改时，直接保存会提示另存副本。页面编辑和提取使用内存处理，生成文件上限 256 MiB；大文件会消耗较多内存。插入或合并会重建文档，可能丢失元数据、书签和复杂批注等结构，请核对输出。检测到签名、表单或 PDF 文件包时限制编辑，但检测不能保证覆盖所有特殊 PDF。强制结束进程时，保存产生的 `.fdp-*.tmp` 临时文件可能留在目标目录。

支持插入 PNG/JPEG 签名图片，放置时可拖动和缩放，确认后成为页面内容；它不是数字证书签名，保存后不能单独重新编辑。可对单页选中文字添加高亮，添加便签和单行中文文字框；可重新打开并编辑或删除 FDP 创建的便签、文字框和高亮，便签可直接拖动移动，也可通过便签对话框移动。文字框支持字号、颜色、加粗、斜体和下划线；旋转页面或旋转阅读视图时暂不支持放置文字框。修改可在本次会话撤销，需要保存或另存副本。复杂 PDF 和第三方批注兼容性仍需验证。

文字框使用本机安装的微软雅黑和 Calibri，程序包不附带这两款字体；保存时会把用到的字形嵌入 PDF，方便在其他设备显示。如果系统缺少字体或字体不允许嵌入，文字框功能会提示错误。其他设备和阅读器的显示效果仍需测试。

扫描件压缩仅允许没有可检测文字层、批注、书签和附件的普通 PDF，最多 100 页；用户可调整 JPEG 质量并比较第一页预览。压缩为有损重建，不保留原 PDF 对象或元数据，请核对全部页面；结果也可能比原文件更大。

打印使用 WebView2 打印预览，预览中可进入系统打印对话框。页面先渲染为位图，目前最多支持 50 页；纸张大小、方向、缩放、混合页面及实体打印机兼容性仍需验证。窗口提供自绘标题栏和边缘拖动缩放；Windows 11 原生贴靠布局菜单尚不支持。

不包含 OCR、批量页面导出图片和恢复草稿。拆分、压缩、默认关联和复杂 PDF 兼容性仍需进一步验证，建议先使用副本试用。Windows 在程序未签名时可能显示提示。

## 开发构建

`scripts/build-webview2.ps1 -SdkPath <已解压的 Microsoft.Web.WebView2 NuGet SDK 目录> -OutputPath <不存在的输出目录>`。需要 Windows .NET Framework 4.7.2 或以上开发环境、x64 编译器，以及包含 net462 和 win-x64 native loader 的官方 WebView2 SDK。SDK、生成目录和测试文件不提交到 Git。构建脚本随包复制 WebView2、PDF.js 和 pdf-lib 的许可。
